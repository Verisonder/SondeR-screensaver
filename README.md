# SondeR Screensaver

A fullscreen terminal screensaver with animated ASCII art.
Built on [terminal-text-effects](https://github.com/ChrisBuilds/terminaltexteffects) and Alacritty.

**By [VerisondeR](https://github.com/Verisonder)**

## Install

```bash
git clone https://github.com/Verisonder/SondeR-screensaver.git
cd SondeR-screensaver
chmod +x install.sh
./install.sh
```

## Run

```bash
sonder-screensaver
```

Press any key to exit.

## Customize

Edit your ASCII art:

```bash
nano ~/.local/share/sonder-screensaver/Yourtext.txt
```

## Uninstall

```bash
rm -rf ~/.local/share/sonder-screensaver
rm ~/.local/bin/sonder-screensaver
```
